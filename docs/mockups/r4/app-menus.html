1File stays for Load LUT… ⌘O (the standard Open key) and Close ⌘W. Edit stays standard for the rename field and selectable text. "Hide from Dock" remains; Settings › General offers the same choice.
2The Camera menu acts on the selected camera (blue ring in the window, ⌘1–⌘4 to change it) and its header says which. ⌘↩ keeps its key and acts on all cameras, matching Program start (D3); stopping one camera has no shortcut and asks first while recording. Add and Rename say why they're unavailable while cameras run.
3Record flips with state: ⌘R for the selected camera, ⌥⌘R for all. Timecode names now say what lands in the file: No Timecode Track, Record Start, Mac Clock. Backup Recording is the D6 proposal.
4Program: output mode (locked while running), cuts that read like tally ("on air"), Auto (⌃⌥A, not ⌃A, which moves the cursor in text fields), Hold Current Shot (the existing manualHold), and Recent Cuts instead of a full director timeline.
5View: layouts, sidebar, strips, inspector, then commands for the selected picture. ⌃⌥F and ⌃⌥C are kept exactly. Zoom uses the standard ⌘= / ⌘−, and Zoom to Fit is ⌥⌘0 so ⌘0 stays the main window.
6Window: the main window (⌘0), detached monitors per camera or Program, and Diagnostics with no shortcut (engineering detail, rarely needed).

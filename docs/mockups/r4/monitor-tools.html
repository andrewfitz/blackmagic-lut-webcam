1At rest a picture shows only identity, tally, REC and small chips for active tools. Hover or keyboard focus (Tab, ⌘1–⌘4) reveals the tool bar, signal, timecode and view controls.
2Every tool is a split button. The icon toggles the tool; the chevron opens its settings popover. No long-press or ⌥-click to discover.
3A click selects the camera (blue ring outside) and never cuts Program. The context menu has no Cut; cuts live in the toolbar, strips, ⌃1–⌃4 and the dropdown.
4Popovers keep today's settings per camera. False color matches the current code: Off / Sony S-Log3 / EL Zone with Sony thresholds. One scope mode per camera.
5Program shows what's possible: source-only tools are dimmed in place with the reason, never hidden or faked.
6View-only states are labelled on the picture. "Monitor unavailable" is the honest state when a presentation is refused under load.
7Detached windows use the same split-button tools with their own target and docked scope.
8Zoom moves to ⌘= / ⌘− and Fit ⌥⌘0, so ⌘0 stays "Main window". Scope is ⌥⌘K.

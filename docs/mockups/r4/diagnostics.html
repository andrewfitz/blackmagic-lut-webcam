2Drops are split by stage so a problem points somewhere. Counts turn orange only above zero; NEW sparklines show when. Large rates read in Gb/s; audio gaps are back.
3The Program tab: published format and whether every source matches it, what's on air and pending, the switcher's evaluation state (including No healthy source), an honest director-mode note, and NEW recent cuts with reasons.
4Each status bar segment opens a popover. Output says "In use", never an app name (the extension only counts clients). Recording shows each take and time left on each camera's drive.
5App tab: Ultracam CPU, GPU (video) and memory with NEW 60 s history, keeping today's help-text caveats.
6Hidden diagnostics stop sampling: no timers or counters run while the window, tab or popover isn't visible.

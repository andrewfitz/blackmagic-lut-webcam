Ultracam UI redesign: mockups, round 1

Three contrasting directions for the main window and menu bar item, built from the inventory in docs/UI_REDESIGN.md. These are static HTML/CSS approximations of macOS 27 Liquid Glass controls, not shipping code. The same state appears in all three: three cameras, Program mode, Feed 1 on air and recording, and Zoom using the virtual camera.

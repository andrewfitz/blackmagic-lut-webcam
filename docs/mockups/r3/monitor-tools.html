1Five fixed overlay zones on every picture. Identity and tally top-left, tools top-right, signal bottom-left, REC bottom-right. Transient controls appear bottom-center on hover only.
2One tap turns a tool on (replacing the old master "Monitor tools" switch); settings sit in its popover. Everything is remembered per feed, as in the current MonitorConfiguration.
3False color matches the current code: Off / Sony S-Log3 / EL Zone, Sony profiles only, honest captions and the exact IRE thresholds in the legend.
4The context menu keeps Reset Monitor Tools and Copy Settings To, so one feed's setup can be copied to another or to Program.
5Program shows what's possible: source-only tools are dimmed in place with the reason, never hidden or faked.
6View-only states (frozen, clean, zoom, reduced, hidden) are labelled on the picture and never affect output or recording.
7Detached windows carry the same chrome with their own target, tools and docked scope.
8Scopes dock at 120 pt or expand to 240 pt, with signal and interpretation footnotes. Monitoring diagnostics stay one disclosure away.

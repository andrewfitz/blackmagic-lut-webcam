1Every state has the same shape: a picture area (live preview, mini previews or a placeholder of the same height) above native-style menu rows. Opening the menu never makes the layout jump.
2In Program mode the camera thumbnails are the cut buttons, with the same red/green tally as the main window. ⌃1/⌃2 work while the menu is open.
3Per-camera submenus hold everything for one feed: cut, recording, effects, LUT, input, monitor window. Rows that don't apply say why (e.g. "Separate mode only") instead of disappearing.
4In automatic mode a visible preview counts as demand and would start capture, so the waiting state shows a placeholder until you choose "Show Live Preview". A failed start offers one explicit Retry, with no background retry loop.
5Problems appear as banners above the rows with one action each. The menu bar icon gets an orange dot NEW, so you notice without opening the menu.
6Icon states mirror the feed: outline when stopped or waiting, filled when processing, arrow when bypassed; a red dot while recording NEW.

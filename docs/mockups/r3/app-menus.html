1File stays: SwiftUI always provides it for Close ⌘W, and putting Load LUT… there gives ⌘O its usual meaning. Edit stays for the rename field and selectable text (timecode, paths, diagnostics).
2Feed acts on the selected feed. Its header says which, and ⌘1–⌘4 change it. Items locked while running say so in place.
3Record items flip with state (Record ↔ Stop). Codec and timecode are quick switches; folders and automation defaults live in Settings.
4Program: output mode (locked while running), cut items that read like tally ("on air", "next"), Auto, strategy, anchor and emphasis.
5View: layouts, sidebar, strips, then commands for the focused picture. The existing ⌃⌥F and ⌃⌥C are kept exactly; scopes move off ⌥⌘W, which macOS uses for Close All.
6Window: the main window (⌘0), detached monitors per feed or Program, and Diagnostics (⌥⌘I).

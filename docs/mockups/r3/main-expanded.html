1The session sidebar holds the whole session: cameras with tally, the Program output with Auto and the shot timer, backup recording and space left, recent takes, and automation.
2No separate Program picture. The feed on air gets a red ring and "ON AIR · Program"; the next cut gets green. Click a picture or press ⌃1/⌃2 to cut.
3Channel strips give each feed its own recording (record, pause, stop, folder, time left) and output (cut, effects, processing, audio). ⋯ opens the rest; the chevron collapses the strip.
4In Program mode the toolbar has cut buttons and Auto. The layout picker adds an optional Program view.
5Collapse all strips (⌥⌘S) to reduce clutter. Record All shows elapsed time and the number of takes.
6Status bar: output → consumer, Program, recording with time left, audio, resources. Each segment opens a popover.

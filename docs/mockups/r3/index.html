Decisions made during this round

  • Shortcuts: existing ⌘↩, ⇧⌘B, ⇧⌘P, ⌃⌥F, ⌃⌥C and ⌘Q are unchanged. New proposals: ⌃1–⌃4 cut, ⌃⌥A Auto (not ⌃A, which moves the cursor in text fields), ⌘R / ⌥⌘R record selected / all, ⌘1–⌘4 select feed, ⌥⌘1–⌥⌘4 layout, ⌥⌘S collapse strips, ⌥⌘K scopes (not ⌥⌘W, which is Close All Windows), ⌥⌘I diagnostics, ⌘0 main window, ⌘O Load LUT. ⌃1–⌃4 clash with Mission Control's desktop switching when that's enabled; plain 1–4 in the focused window is the fallback.
  • Tally colors: red = on air (Program, or a consumer using that feed's camera), green = next, dashed red = manual cut waiting for the next frame, orange = paused or skipped by Auto (unhealthy source). Never color alone; every ring has a text badge.
  • Automatic mode: opening the dropdown doesn't show a live preview while waiting, because a visible preview counts as demand and would start capture. "Show Live Preview" is explicit.
  • Menus: File (Load LUT ⌘O, Close ⌘W) and Edit (rename, copy values) stay in the app's menu bar.
  • Code drift found: false color in the working tree is now Off / Sony S-Log3 / EL Zone, with Sony profiles only. The mockups follow the code; the README still describes ARRI.
